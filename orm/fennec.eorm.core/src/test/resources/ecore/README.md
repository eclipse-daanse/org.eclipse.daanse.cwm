# Ecore test data

The Ecore models of the class models the tests map, written by a CWM-to-Ecore conversion (default
options) and stripped of every annotation under `http://daanse.eclipse.org/cwm/`. They
carry names only, so the tests show that the EORM conversion finds classes and features by names.
Do not edit them; write them again when the class models change.

| Folder | Class model |
| --- | --- |
| `fixture/library.ecore` | the class model of the test `Fixture` (package `library`) |
| `corpus/<name>/*.ecore` | the class model each corpus file maps (`../corpus`), one folder per tutorial: `01-entity-basic` … `23-lifecycle-listeners` (`library.ecore`) |
